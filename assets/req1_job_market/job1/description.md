# Thông tin Việc làm QA/QC #1

## 1. Thông tin Chung
* **Vị trí công việc (Title):** Senior QA/QC Automation Tester (AI-Assisted)
* **Công ty (Company):** Bosch Global Software Technologies
* **Địa điểm:** Thành phố Hồ Chí Minh (Q. Bình Thạnh)
* **Mức lương (Salary):** 1,800 - 2,800 USD/tháng

## 2. Mô tả Công việc (Job Description - JD)
- Thiết kế, phát triển và bảo trì các kịch bản kiểm thử tự động cho hệ sinh thái phần mềm IoT, web và ứng dụng OutSystems.
- Tích hợp kiểm thử tự động vào quy trình CI/CD nhằm phát hiện lỗi sớm.
- Đánh giá và triển khai thử nghiệm các công cụ sinh mã tự động bằng AI (ví dụ: GitHub Copilot, Diffblue) để tăng tốc độ viết mã kịch bản kiểm thử.

## 3. Kỹ năng Yêu cầu (Required Skills)
- Playwright, Selenium, Python hoặc TypeScript.
- Kỹ năng tích hợp CI/CD (Jenkins, GitLab CI/CD).
- Tư duy ứng dụng AI trong tối ưu hóa kiểm thử tự động.

## 4. Phân tích Tác động của AI (AI Impact Analysis)
*AI đóng vai trò trợ lý đắc lực giúp lập trình viên viết nhanh mã kiểm thử tự động (boilerplate code), giảm 30-40% thời gian code thủ công. Tuy nhiên, con người vẫn bắt buộc phải có để phân tích thiết kế hệ thống và sửa lỗi khi AI sinh mã không chính xác.*
