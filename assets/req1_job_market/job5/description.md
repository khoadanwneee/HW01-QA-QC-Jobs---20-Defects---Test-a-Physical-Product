# Thông tin Việc làm QA/QC #5

## 1. Thông tin Chung
* **Vị trí công việc (Title):** Senior QC (Automation Tester, QA/QC)
* **Công ty (Company):** PNJ (Phu Nhuan Jewelry)
* **Địa điểm:** Thành phố Hồ Chí Minh (Q. Phú Nhuận)
* **Mức lương (Salary):** 1,500 - 2,200 USD/tháng

## 2. Mô tả Công việc (Job Description - JD)
- Thiết kế và chạy các kịch bản kiểm thử tự động cho hệ thống ERP và trang thương mại điện tử bán lẻ trang sức lớn của PNJ.
- Thực hiện kiểm thử hồi quy tự động nhằm đảm bảo tính ổn định của hệ thống trước mỗi đợt phát hành.
- Tối ưu hóa hiệu năng cơ sở dữ liệu bán hàng.

## 3. Kỹ năng Yêu cầu (Required Skills)
- Sử dụng tốt Selenium Webdriver, Appium hoặc Katalon Studio.
- Lập trình Java hoặc Python, truy vấn SQL Server tốt.
- Có kiến thức về CI/CD.

## 4. Phân tích Tác động của AI (AI Impact Analysis)
*AI thúc đẩy việc kiểm tra tự động các luồng thanh toán và cập nhật giỏ hàng hàng loạt. Tuy nhiên, việc đánh giá trực quan hình ảnh trang sức cao cấp hiển thị trên các màn hình thiết bị di động thực tế vẫn yêu cầu QC kiểm tra thủ công.*
