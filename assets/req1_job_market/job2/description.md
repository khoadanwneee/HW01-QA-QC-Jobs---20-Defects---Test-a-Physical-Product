# Thông tin Việc làm QA/QC #2

## 1. Thông tin Chung
* **Vị trí công việc (Title):** Senior / Principal Automation Tester (AI-Augmented)
* **Công ty (Company):** KMS Technology
* **Địa điểm:** Thành phố Hồ Chí Minh (Q. Tân Bình)
* **Mức lương (Salary):** 2,200 - 3,500 USD/tháng

## 2. Mô tả Công việc (Job Description - JD)
- Thiết kế, phát triển và tối ưu hóa khung kiểm thử tự động (Automation Framework) cho các hệ thống phần mềm doanh nghiệp lớn.
- Ứng dụng các công cụ AI (như Applitools AI Visual Testing, GitHub Copilot) để kiểm tra giao diện tự động và tối ưu hóa tốc độ viết mã.
- Nghiên cứu cơ chế tự sửa lỗi kịch bản kiểm thử (AI self-healing scripts).

## 3. Kỹ năng Yêu cầu (Required Skills)
- Lập trình Java hoặc Python tốt, kinh nghiệm với Selenium, TestNG.
- Sử dụng thành thạo các nền tảng AI-powered testing hoặc AI coding assistants.
- Kỹ năng tiếng Anh lưu loát để trao đổi với đối tác quốc tế.

## 4. Phân tích Tác động của AI (AI Impact Analysis)
*Hệ thống AI giúp tự động hóa khâu viết code mẫu và tự sửa lỗi định vị giao diện (self-healing), giảm tải 40% công việc thủ công của kỹ sư. Tuy nhiên, Principal Engineer vẫn cần thiết để lập chiến lược và kiểm định tính bảo mật hệ thống.*
