# Thông tin Việc làm QA/QC #9

## 1. Thông tin Chung
* **Vị trí công việc (Title):** Automation QA Engineer (Nakivo Backup)
* **Công ty (Company):** Nakivo
* **Địa điểm:** Thành phố Hồ Chí Minh (Q. 1)
* **Mức lương (Salary):** 1,200 - 2,000 USD/tháng

## 2. Mô tả Công việc (Job Description - JD)
- Thiết kế và chạy các kịch bản kiểm thử tự động cho giải pháp sao lưu và phục hồi dữ liệu ảo hóa (Nakivo Backup & Replication).
- Giả lập các kịch bản lỗi phần cứng, mất kết nối mạng để kiểm tra tính năng khôi phục thảm họa (Disaster Recovery).
- Viết script Python/Bash trên môi trường Linux.

## 3. Kỹ năng Yêu cầu (Required Skills)
- Tư duy lập trình Java tốt, viết script Python/Bash.
- Sử dụng tốt hệ điều hành Linux và hệ thống ảo hóa (VMware ESXi, Hyper-V).
- Kiến thức về mạng và lưu trữ dữ liệu.

## 4. Phân tích Tác động của AI (AI Impact Analysis)
*AI hỗ trợ viết các đoạn mã script tự động hóa hạ tầng ảo nhanh chóng. Tuy nhiên, việc chuẩn đoán lỗi khôi phục dữ liệu ở cấp độ phần cứng và ảo hóa sâu đòi hỏi kỹ sư QA có kinh nghiệm hệ thống chuyên sâu phân tích thực tế.*
